AI PASSPORT 小智版 2.1.0-xiaozhi.21

基线：默认固件 2.1.0-preview.45 的 798 文件快照。
硬件为 ESP32-C3 / 8 MB。传统 USB 分段版的设备身份、用户配置和 Wi-Fi 存储地址沿用 .14。
小程序合并版使用 partitions-miniapp.csv，供协议 4 的常驻安装器下载。
.20 加入手动添加隐藏 Wi-Fi、城市天气和在线 MP3 电台。小程序版收紧只读素材填充，网络、主题及恢复分区的地址未动。
.19 修复 .17 直接用 USB 覆盖后恢复区残留数据导致的开机重启。安装与构建步骤见 README。
.15 在原只读素材区内重排图像和字库，分出 920 KiB 的官方主题区及 92 KiB 的表情缓存。

使用 ESP-IDF v5.5.3，依赖版本见 dependencies.lock。
初始化 ESP-IDF 环境后，在本目录执行：
  idf.py build
  python scripts/release.py
  python tools/verify_release.py releases/<生成的ZIP> --build-dir build

首次构建需要 ESP-IDF 自动获取锁定的 managed_components。
源代码包不含 SDK、编译工具、下载缓存、设备凭据或设备备份。
生成后的字体已经随源码提供；仅重生成字体时需要 Pillow 与 lv_font_conv@1.5.3。

本版主要改动：
1. board_config.h 中 PASSPORT_XIAOZHI_EDITION=1。冷启动、重启及深睡唤醒均通过
   app_plays_open_xiaozhi 进入正常小智流程。保留按住确认键上电的原有自检入口。
2. 不显示首页扫码页、不启动首页头像解码和旧 RTTTL 开机曲；冷启动先播放品牌动画，深睡唤醒待小智首帧完整绘制后亮屏。
3. 右侧菜单：重新配网、调整音量、打断方式、智能体设置、屏幕亮度、休眠时间、返回。
4. 返回回对话；对话页长按确认打开菜单。音量/打断方式保存失败留在编辑页供重试。
5. 更新原生4bpp字库，常用子集补齐六个提示用字，去除备用字库中的重复字符。
6. 结束语音后释放编解码器、麦克风、语音套接字与TLS客户端，保留无线连接与形象。
   上下键按下时切换焦点，短按确认在松手时执行，长按后的松手不触发第二次操作。
   常规会话结束和完整退出分别处理；配网、退出及关机仍执行完整清理。
   voice,end / voice,resume 是本地串口诊断入口，调用与界面相同的会话控制操作。

7. 麦克风连续 30 秒未检出人声或 ASR 表达直接告别意图时，先关闭云端语音输入，再播放随固件提供的“拜拜”，最后进入在线待机。
   聆听时的 16 kHz WebRTC VAD 复用原有 2,880 字节 PCM 缓冲区的尾部。回复播放时间不计入，云端自动续接保留已测得的静音。
   告别短音频和来源分别位于 components/platform/xiaozhi/farewell_zh.adpcm 和 assets/licenses/FAREWELL-SOURCE.txt。

8. 配网页按设备的休眠设置等待，默认为 5 分钟。手机扫描网络或提交配网会刷新整机空闲计时。
   关闭自动休眠时可持续等待。从配网页休眠后按任一功能键返回配网，包括已保存旧网络时的“重新配网”。

9. 开机品牌动画结束后显示当前虚拟形象。没有保存网络时，在“配置网络”按钮完成绘制后播放离线欢迎语。
   按右侧最下方确定键可以打断播报并进入原配网页。已有网络自动连接，主动重新配网直接进入表单。
10. 回复、引导及告别的嘴型读取 ES8311 扬声器通道已经发送的非静音 DMA 块。沿用原按键和自然打断两条音频路径。
    参考 78/xiaozhi-esp32 主分支 a73e9a7e266e3196d1368ba46c30bee0d81f0a64 的音频输出分层和 MQTT 关闭逻辑。
    对方已结束的会话不会再次回发 goodbye，其他会话的具名结束消息会被忽略。保留旧端未带会话 ID 的关闭格式。
11. 首页与小智界面使用相同的 CW2017 实测电量条，有效电量只显示填充，未知电量显示灰色短线。

12. 空回复结束后继续聆听。UDP 发送遇到临时缓冲不足时复用原数据包，最多重试两次，
    总等待 20 毫秒。持续拥堵时丢弃当前实时帧，继续处理下一帧和结束操作。
    永久套接字错误、数据长度或加密错误仍返回失败。重试不会重复加密或增加本帧序号。

13. 开机引导改用用户 2026-11-06 提供的录音，保留原生 24 kHz / PCM16，
    240 字节分块读取 Flash。原文件及再生成脚本见 assets/source/audio、tools/prepare_welcome_pcm.py。
    去掉首尾极低电平静音，保留前 80 毫秒、后 100 毫秒余量；语音样本及音量不变。
14. 小智界面采用深蓝黑底、暖杏焦点、卡片菜单和大音量刻度；圆角外保持黑色。
    动画仍由实际声音驱动，焦点和对话更新保留对象，不增加全屏图片或动画任务。
    大数字使用 Passport Volume Digits，仅含 0–9，来自随 SDK 提供的 Montserrat。
    原字形及 SIL OFL 许可保留；tools/prepare_volume_digits.py --check 可核对生成结果。
15. 校准 ES8311 音量曲线，修正默认补偿在 95/100 音量下产生的正增益，
    最大 DAC 增益限制在 -4.5 dB；自然打断保留旧版约 -6.5 dB 的声学输出上限。
    停止音频时先静音，再停时钟。主机验证不替代实机杂音听感验收。

16. 已配置设备复用 NVS 内保存的 MQTT 连接参数，正常重开对话或重启不再请求绑定配置。
    缓存上限 4096 字节，绑定设备身份并校验字段，只保存连接参数，不保存 UDP 会话密钥。
    相同内容不重复写 Flash；连接失败时完整释放旧连接后最多刷新一次云端配置。
    仅服务端返回有效激活码时进入绑定页，网络失败不会自行要求重新绑定；TLS 校验保留。
17. 收到回复文字但没有任何音频写出时，TTS 结束后留 1.5 秒延迟容限，随后自动重建语音连接一次。
    TTS 开始后一直没有音频且没有结束信号时，等待上限为 10 秒。真正没有文字的空回复仍继续聆听。
    连续两次无声会话进入在线待机，保留 Wi-Fi 和形象，按“对话”可重试；成功播放会清零失败计数。
    日志补充收发错误码与信号强度，不输出设备凭据或对话内容。
18. 男生发声帧使用原生圆角几何补绘更明显的开口，停声闭嘴，女生保持原表情。
    沿用 180 毫秒开合节奏及实际扬声器输出判定，无新位图、动画任务或常驻缓冲区。

19. .10 将正文与标题的字符范围统一为 7,035 个字符，包含 GB2312 全部 6,763 个汉字、
    已有姓名用字、标点和补充口语字。两种字号仍使用原生 4bpp 抗锯齿。
    正文 BDF1 字形、度量和 Unicode 索引置于现有只读 petart 分区 +0x10000，
    原有 7 张 PSR1 共享素材保持不变，分区布局不变。新增字库直接映射 Flash，
    不占完整 RAM 缓存；标题按需解压仍只需最多 512 字节临时堆内存。
    gen_font_oracle.py 生成独立未压缩字形的像素校验基准；font_mapped_all_glyphs
    执行生产资源加载器与真正打包后的 C 字库，逐字核对两种字号的全部字符。
    升级必须配套刷入本版 petart.bin、companion.bin 和应用，不能只更新应用 BIN。

20. .11 冷启动显示 约 3.5 秒 FoloToy 品牌动画及产品固件 open.mp3 原音频。
    单个 A4 Flash 蒙版共 2,232 字节；单个 33 ms LVGL 定时器，在首帧后约 2600 ms 暂停并于进入小智时销毁。
    音频复用已校准输出和分块解码路径，16 kHz / 50,502 样本；音频写入不占用 LVGL 锁。
    开机资源及来源见 assets/source/boot 与 assets/licenses/BOOT-SOURCE.txt。
21. XZ_STANDBY 不再刷新忙碌计时，默认空闲五分钟触发既有完整深睡流程。
    参考 FoloToy/folo-ai-passport-firmware-demo 的 39228a9 硬件休眠策略，
    保持 CW2017/ES8311/LCD 关断顺序和 GPIO0 唤醒、输入取消保护。
    profile v16 -> v17 迁移保留既有字段，10 分钟默认值改 5 分钟，亮度新增默认 100。
    在线待机并不关闭 Wi-Fi；真正深睡会关闭无线，按键唤醒重新连接已保存网络。
22. 菜单增加亮度与休眠设置，七项按五行窗口滚动，不增加整页切换动画。
    亮度 10%–100% 按 5% 步进实时预览；确认写入 NVS，取消或保存失败恢复旧值。
    休眠档位 0/1/3/5/10/15/30/60 分钟，0 关闭自动休眠。唤醒首帧使用保存的亮度。
    AT+CONFIG=common,brightness,? / standby_time,? 是只读诊断，不更新空闲计时。

23. .14 使用用户提供的 folotoy-logo-pink.png 横排字标，保留原始形状、比例和粉色。
    144x31 像素，占 240 像素屏宽的 60%，从屏幕上方整体匀速下移，2.6 秒后停在中央。
    参考经典 Game Boy 的简单滚动节奏；纯黑背景，仅一个图像对象，品牌音频逐字节保持。
24. 动画从真实首帧绘制时开始计时，首帧延迟也不会跳过起始姿态。
    播放期间隐藏被覆盖的原活动页面，避免 LVGL 仍绘制其字形和背景；关闭时恢复原透明度样式。
    原生回归覆盖延迟首帧、单向滚动、仅 Logo、底层不绘制、页面恢复及 100 次开关无泄漏。

25. .21 保留查询期间的 24 KiB Opus 连续内存；只向同一工作任务的临时 HTTPS 请求出借。
    HTTP 清理后归还，MQTT 和其他任务仍使用系统分配器，恢复收听无需重新申请这块连续内存。
    电台移交时先保留 MP3 解码器最后申请的 8 KiB 工作区，HTTPS 建立连接后再分配其余状态。
    固定 TLS 接收缓冲避免直播过程中反复申请大块内存；较小的解码状态可使用预留区空闲尾部。
    TLS 与解码块分别计数、按地址释放，HTTP 完成后关闭解码器，停播/换台/取消均清理同一条路径。
    PASSPORT_TEST_SERVICES 仅用于本地实机固定天气/电台请求；交付的 USB 与小程序构建均为 OFF。

26. .22 电台网络生产者与音频消费者分开，压缩队列固定 8 KiB，不再额外占用 8 KiB 系统堆。
    起播填充 3/4，断粮后填充 1/2；HTTP/HTTPS 共用这一预算，任务栈分配失败可正常返回。
    队列、MP3 输入和 PCM 暂存使用已有 28 KiB 语音工作栈；6 KiB 音频任务只在电台播放时存在。
    队列以原子发布索引传递数据；取消、网络结束和失败均先等待消费者释放音频、解码器，再删除任务。
    解码任务登记为受限的 radio_owner，可借用预留解码区；TLS 借用仍只允许网络工作任务。
    PCM 跨 MP3 帧拼成 120 样本整块写入，避免帧尾半 DMA 块；起播/恢复淡入 120 样本。
    连接/响应头等待为 6 秒，直播响应后单次读等待为 300 ms，持续无数据 8 秒才结束；API 总时限 9 秒。
    不改全局音量曲线、不删减字体/形象；电台上键换台，下键返回，OK 保留兼容停止行为。
    原始 C3 ELF 解码回放覆盖 10 路 MP3、完整 DMA 块、双任务切换、取消和全部分配失败清理。
    实机听感、长时联网播放和实际栈余量以随包测试记录为准，模拟回放不替代这些检查。

27. 参考 manchunx7-bit/passport-os 的 b70879b3c4be0751cb728b8b0c421dd2d1524fdb：
    main/apps/radio/radio_player.cc 的先 join 再释放、按容量预缓冲与断流恢复，
    components/bsp/include/bsp_audio_workspace.h 的前台音频互斥复用，以及 sdkconfig.defaults 的动态 RX 上限。
    本项目继续使用已有按需分配的 Opus/TLS 区和小智工作栈，不额外常驻分配上游 48 KiB 工作区。
    仅内置公开 qingting 广播使用提供商原生 HTTP；不发送设备凭据，不改写目录里的 HTTPS 地址。
    查询、设备绑定和官方主题继续校验 HTTPS 证书；内置广播音频传输本身不加密。
    小智 Wi-Fi 初始化使用静态 RX 4、动态 RX 上限 8、AMPDU RX/TX 与 RX BA 窗口 4。
    TCP 接收窗口 11520 字节、邮箱 10、SACK 开启；回收原扩展 FIFO 的堆空间支撑在途数据包。
    2026-11-11 实机五分钟深圳音乐广播：2403328 字节、11453 帧、零次缓冲耗尽；
    主动结束后回到在线待机，再查天气两路 HTTPS 成功并恢复收听；未出现分配失败或重启。
    这一轮播放最低堆余量 7556 字节；后续天气 HTTPS 峰值最低 4200 字节，查询后约 29 KiB。
    数字验证不等同于用户听感验收；试听与最终交付镜像状态见安装包内测试记录。
    网络读失败先清理整次播放，最多再连两次；解码/内存失败和主动下键/换台立即交还控制。
