# 蓝牙翻页笔：输入方式与兼容边界

入口区分“安卓刷视频”“iPhone 刷视频”和“电脑翻演示”。系统蓝牙中选择屏幕显示的 `AI PASSPORT XXXXXX`。手机保持竖屏，打开抖音／小红书／视频号；不同应用对外部输入的处理仍需实测。

| 用途 | 上／下键 | 设置与边界 |
| --- | --- | --- |
| 安卓 | 屏幕中央单指绝对触控，上一条／下一条 | OPPO Find N5 外屏已有用户切换视频反馈；不能据此保证所有厂商内核或展开屏 |
| iPhone | 按住鼠标主键、垂直拖动、松开、原路移回 | 先开启“设置 → 辅助功能 → 触控 → 辅助触控”及“执行触控手势”；圆点应在屏幕中间 |
| 电脑 | 演示文稿翻页键 | 确定菜单提供开始演示、结束演示和暂时隐藏画面 |

确定菜单可以反转手机方向、测试鼠标移动、重新选择用途或换设备。“换一台设备”先释放输入，再断开并清除本机当前配对记录；到新设备的系统蓝牙中重新连接。

## 退出后与小程序连接

退出翻页笔仍会先释放按下的输入、结束本次 HID 连接，再恢复以完整 SN 命名的普通广播。
已配对手机随后自动重连时，固件保留普通 BLE 链路及原配对记录，允许恢复已有链路加密；
不会因“已配对但未启用翻页笔”而循环断开，也不会在普通模式发送键盘、鼠标或触控报告。
显式退出、换设备和休眠的连接边界仍有效，普通模式不会自动替换旧的 HID 配对记录。

当前最多同时连接一台中央设备。若此前配对的电脑/手机已自动连上，另一台手机无法同时连入；
需先在原设备断开连接，或通过翻页笔菜单“换一台设备”处理原配对。

排查日志时：`reason=534（0x216）` 是本机终止连接；MTU 或加密回调中的 `status=7`
是 NimBLE 的“连接已断开”，可能出现在 GAP 断连日志之前，不能据此认定 MTU 不兼容或密钥错误。
真正的加密失败仍会按错误处理；已断连的协商不会继续降档、重试或重复请求断开。

## Android 触控声明

HID Digitizer 使用 Pen application / Finger physical usage，让通用 Linux HID 路径声明直接单指输入，避免被识别为相对鼠标。中央轨迹避开屏幕边缘。

分析依据：[Linux v6.6 hid-input](https://github.com/torvalds/linux/blob/v6.6/drivers/hid/hid-input.c)、[hid-multitouch](https://github.com/torvalds/linux/blob/v6.6/drivers/hid/hid-multitouch.c) 和 [AOSP 触控设备说明](https://source.android.com/docs/core/interaction/input/touch-devices)。这是源码依据，未采集手机内核输入事件。

## iPhone 拖动与释放

实测中鼠标能够出现，但单独发送滚轮未使设置列表滚动。当前改为七段输入：按下、两段垂直移动、松开、两段反向移动、空闲。沿用 25 ms 调度器及六字节鼠标报告；不会在连接后自动移动，也不会每次把圆点推到角落。

参考 [杰理官方 keypage 实现](https://github.com/Jieli-Tech/fw-AC63_BT_SDK/blob/fdc018de81629e21e594d677cf05f87d288be0f0/apps/hid/examples/keypage/app_keypage.c) 的 iOS 手势顺序，状态机在本项目独立实现。[Apple 辅助触控说明](https://support.apple.com/zh-cn/111775)介绍指针使用及自动隐藏；圆点消失本身不能证明断连。

相对位移总和为零不保证屏幕位置完全恢复：系统加速、边缘裁剪和跟踪设置可能产生偏移，固件无法读回手机坐标。iPhone 17 设置列表双向拖动已有用户确认，尚无全部视频应用和长时间连续操作的逐项验收。

发送失败时不重试移动，转为释放已按下的输入；退出会取消剩余手势并释放，连续三次释放失败则断开连接。行为测试覆盖每个阶段退出、反复手势、释放失败／重试／断开、实际通知长度和路由。自动化不能替代手机端点击、滑动和断连测试。
