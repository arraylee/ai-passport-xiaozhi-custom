# 多台设备的蓝牙命名

翻页笔模式使用 `AI PASSPORT XXXXXX`，例如 `AI PASSPORT 12AB34`。

- 六位编号取自本机 Wi-Fi 基础 MAC 的后三字节，使用大写十六进制，保留前导零。它和默认 SN 的后六位对应；不取会偏移的 BLE 地址、不取昵称、不生成随机数。
- 安卓、iPhone、电脑用途使用同一个名字。配对页、已连接页及“换一台设备”说明使用平台提供的当前名称。
- 小程序仍用原来的完整 SN 广播。产品身份、二维码内容、GATT 服务、HID 报告和配对存储不因改名而变化。
- 名称只在初始化时生成一次，复用已有 32 字节状态字段。硬件标识读取异常时停用翻页笔，避免以通用名字广播。

完整翻页笔广播为 31 字节，保留完整名称、HID 服务 UUID 和设备类型。Host 测试调用 ESP-IDF 实际广播序列化器，覆盖不同设备、前导零、读取失败、普通广播恢复和三种用途。原生 LVGL 测试验证配对及换设备页面的实际名称和边界。

preview.27 已刷入测试设备，启动日志确认包含硬件编号的名称。手机可能缓存旧配对名；固件不会为改显示名自动删除配对。运行时名称检查不等于所有手机的缓存刷新验证。
