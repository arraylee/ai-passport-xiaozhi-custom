# AI PASSPORT 小智版

适用于 AI PASSPORT ESP32-C3 / 8 MB 板卡的独立固件，沿用已经验证的默认固件硬件支持与小智交互升级。

当前版本 **2.1.0-xiaozhi.22**，小智控制台上报版本 **2.1.0.22**，使用 **ESP-IDF v5.5.3** 构建。

## .22 电台缓冲与返回操作

- 电台接收和播放分别处理，先蓄足缓冲再起播，断流后最多自动重连两次；下键可随时取消重连并返回。
- 调整 Wi-Fi 聚合接收、TCP 窗口及丢包恢复；压缩音频使用工作栈内的 8 KiB 队列，给网络接收留出内存。实机五分钟连续播放记录为零次缓冲耗尽，随后天气查询成功。
- 音频连续拼成与声卡一致的完整分块，消除 MP3 帧尾不足一块的写入；起播和重新缓冲后的声音渐入。保留音量设置与原有音量曲线。
- 电台页改为**上键换台、下键返回**，底部显示「下键 · 返回」。返回后停止电台，保留 Wi-Fi，按「对话」可以续聊。
- 参考 [Passport OS 电台实现](https://github.com/manchunx7-bit/passport-os/blob/b70879b3c4be0751cb728b8b0c421dd2d1524fdb/main/apps/radio/radio_player.cc) 的资源交接、预缓冲和重连策略。内置公开广播使用音源方的 HTTP 直播入口，目录提供的 HTTPS 地址照常使用 HTTPS；动态 Wi-Fi 接收上限增加以容纳突发数据。

## .21 界面与联网播放修订

- 卡上的配网指引上移，放大热点名和浏览器地址，保留两步配置与手动添加隐藏网络的入口。
- 天气和电台查询保留语音所需的连续内存，临时联网缓冲在查询结束后归还；工具调用文字改为“正在查询天气”或“正在查找电台”。
- 电台有独立的收听页面，显示台名、播放状态和随声音活动的轻量声条。直播使用固定网络缓冲，提前保留解码所需的大块内存，待连接建立后再启动解码；复用缓冲里的空闲空间，为无线接收留出余量。

## .20 配网、天气和电台

- 首次开机按「配置网络」，或在菜单选「重新配网」。用手机连接卡上显示的热点，打开 `192.168.4.1`。可从「附近网络」选取 2.4 GHz Wi-Fi，也可在「手动添加网络」输入隐藏网络的完整名称和密码。开放网络勾选「无需密码」。提示连接并保存后回到卡上，按屏幕指引完成绑定。
- 说「今天天气怎么样」。第一次未提供城市时，小智会询问并记住城市；也可直接问「深圳明天会下雨吗」。临时查其他城市会保留原常用城市，说「把常用城市改成杭州」可更换。天气数据及城市搜索来自 [Open-Meteo](https://open-meteo.com/)。
- 说「支持哪些电台」或「深圳电台」听选台列表，说「第二个」「还有哪些」继续选台，也可直接说「播放深圳音乐广播」。北京、深圳等有内置台；其他城市会查询 [Radio Browser](https://www.radio-browser.info/) 的 MP3 直播目录。播放时上键换台、下键返回，回到在线待机后按「对话」续聊。

## .19 安装与启动

从 .17 用 USB 覆盖安装 .18 时，旧形象数据可能被误认为上一次安装中断，导致卡反复重启。.19 会识别安装器的中断标记，并在进入常驻恢复程序前校验它的镜像。直接 USB 刷入的卡可以正常打开小智。已用同一张 .17 实机复现故障，验证 .19 首次配网入口、使用已保存 Wi-Fi 的语音回复、结束与续聊，以及软件重启。

用于 [FoloToy 小程序玩法安装器](https://github.com/FoloToy/ai-passport-miniapp-installer/blob/main/README.zh_CN.md)的文件是以 `-miniapp.bin` 结尾的合并固件，**5,687,560 字节（5.69 MB）**。保留小智对话、语音调节、官方主题、多语言字库、开机音乐和两个动态形象。人物帧无损压缩，显示时按四行解开；官方主题包空间仍为 920 KiB。为给常驻安装器留空间，自传相册/头像的 JPEG 上限改为每张 28 KiB，自传音频分区为 80 KiB。这些限制不作用于小智对话语音。

1. 通过微信小程序安装时，卡上需已有**协议 4** 的小程序玩法安装器。首次安装或从旧协议升级，请先按[官方说明](https://github.com/FoloToy/ai-passport-miniapp-installer/blob/main/docs/development/engineering/ble-recovery-compatibility.zh_CN.md)通过 USB 刷入安装器的**首刷整包**。此操作会清除原玩法和配置。小智的 BIN 不含常驻安装器。
2. 在安装模式下，从 AI Passport 微信小程序的「设备」页连接卡，首次配置 2.4 GHz Wi-Fi。待玩法 72 上架此版本后，在社区打开「小智 AI 对话机器人」，确认显示 **.22**，点「安装到设备」，保持供电和联网直到重启。以后关机后同时按开机键和上键，可重新进入安装模式。
3. 小智会优先尝试已有的可用网络，也可在菜单「重新配网」。通过小程序换装会重置小智本地设置；若屏幕显示激活码，请按提示绑定，音量、形象或自定义主题需要重新选择。此包不用于旧版 USB 保留配置升级。

## 使用体验

- 开机直接进入小智；未配网时播放离线引导录音，按屏幕提示配置 Wi-Fi、绑定设备。
- 右侧菜单：**重新配网、调整音量、打断方式、智能体设置、屏幕亮度、休眠时间、返回**。
- 支持按键打断和自然打断；音量设置保存到设备。
- 安静 30 秒或识别到直接告别意图时，播放“拜拜”后进入在线待机。点击“结束”也只结束当前对话；Wi-Fi 和形象保留，按“对话”再次开始。
- 正常开始对话复用已保存的连接配置；连接失败后才刷新配置，只有服务端返回有效激活信息时才进入绑定流程。
- 有回复文字却没有语音时，自动尝试恢复一次；连续失败后保留在线待机，避免无限重连。
- 深色圆角界面、两种动态形象、实际声音驱动嘴型、CW2017 实测电量显示。
- 保留原硬件的自检、休眠及配置能力；没有增加完整字库的内存缓存。

## 官方主题、语音设置与多语言字幕

- 对话页打开“形象”，用上下键选到“官方主题”，短按确认。32×32 的内置表情直接居中显示在页面上。装入兼容的官方主题包后，表情、字体和配色会随之切换。带壁纸的主题包会显示自带的壁纸，缺字会继续查找卡上的字库。
- 已绑定的卡按“对话”保持在线。在小智控制台或官方主题工具中选择这台设备，按 ESP32-C3、240×320、RGB565 制作或选择主题，推送并按工具提示重启。主题包上限 920 KiB，建议使用 32 像素表情和 14 像素 1bpp 字体。下载失败后按“对话”即可继续使用内置表情。包里的唤醒词模型不参与这版的按键对话。
- 聊天时可以说“音量调到 80”“声音小一点”或“屏幕亮度调到 40%”。音量可调 0–100%，亮度可调 10–100%，与菜单设置共用并保存。
- 标题和正文支持现代韩文全部 11,172 个音节，补齐日语、繁体中文常用字，以及越南语、希腊语、西里尔字母和多种拉丁字母语言。保留原有简体中文字库。此项升级针对对话文字显示，菜单沿用中文。
- 仅用本包六段升级可以保留 .14 的设备身份、Wi-Fi 和本地偏好。新主题有单独的下载区，两个原有动态形象可随时切回。

## .14 开机 Logo

使用用户提供的横排粉色 FoloToy 原始字标，仅显示 Logo，背景为纯黑。参考经典 Game Boy 的整块字标下移：144×31 像素，占屏宽 60%，从上方匀速移到中央，约 2.6 秒停稳，留白更宽。品牌开机音乐、亮度、休眠及对话功能沿用 .11。

单个只读 A4 蒙版共 2,232 字节，不增加全屏缓存，停稳后停止动画刷新。动画从实际首帧绘制后开始计时，播放期间暂时隐藏被遮盖的主页，避免仍在下面绘制和解压字形；切入小智或中断时恢复原页面的可见状态。

## .11 开机与省电

- 冷启动和重新开机播放约 3.5 秒的 FoloToy 字标动画，搭配 MagicBox 产品固件的 FoloToy 品牌开机音（含音乐）；四周保持深色。深睡唤醒跳过动画和音乐，直接回到小智。
- 结束对话进入在线待机后，默认空闲 **5 分钟**进入深睡；聊天或操作按键会重新计时。待机保留 Wi-Fi，深睡关闭无线和外设，按任一功能键唤醒后自动重连。
- 菜单中的“休眠时间”支持 1、3、5、10、15、30、60 分钟以及不自动休眠。“屏幕亮度”支持 10%–100%，上下键实时预览，短按确认保存，长按返回取消。
- 参考默认固件的外设关断顺序：先完成语音清理，再关闭电量计、音频、无线和屏幕，最后进入芯片深睡。保留按键取消休眠的保护。未使用功耗仪测量电流。
- 已有 .10 配置自动迁移：原默认 10 分钟改为 5 分钟，其他自定义时间保留，亮度初始为 100%；Wi-Fi、绑定、音量和形象保留。

素材来源见 [开机资源说明](assets/licenses/BOOT-SOURCE.txt)。动画直接绘制小尺寸 Flash 蒙版，不解码视频，也不保留全屏动画帧。

## .10 字库修复

正文此前只覆盖 GB2312 一级汉字，缺少“嗯、呦、嗨、诶、噢、喔、嘞、嘟”等二级字。本版把 16px 正文和 20px 标题统一到完整 GB2312 汉字、既有姓名用字、常用标点及补充口语字，两种字号各覆盖 **7,035 个字符**。

原生 4bpp 字形、字号和抗锯齿保持不变。正文的字形、索引和度量信息放入现有只读资源分区的空闲区域，直接映射读取；分区边界、设备身份、Wi-Fi 和用户配置区域均未改变。

新增测试通过实际固件的资源加载器和打包后字库，逐字核对 **14,070 个字号/字符组合、4,130,350 个像素**，并覆盖资源损坏、映射失败、失败清理与重复初始化。覆盖范围是上述字符集合，不代表全部 Unicode 或 emoji。

## 传统 USB 分段安装

使用同一版本发布包中的六段镜像：启动程序、分区表、应用、头像资源、共享资源及完整中文字库、形象资源。**.9 升级到 .10 需要完整固件包，不能只刷应用 BIN。**

解压固件 ZIP 后，在解压目录使用 ESP-IDF 附带的 esptool，按包内六段地址升级：

```sh
python -m esptool --chip esp32c3 --port <设备串口> --baud 460800 write_flash @flash_args
```

正常升级保留数据，不执行整片擦除或重建设备身份。各段地址由包内清单给出，发布工具会校验镜像与资源是否匹配。仓库的网页刷写器是**产线身份初始化工具**，会另外写入设备身份分区；已有设备的常规升级请使用上述流程。

本版软件测试及具体设备验收状态见发布包中的测试记录。主机测试不能代替实机声音、屏幕和网络验收。

## 构建

先安装并启用 ESP-IDF v5.5.3，进入本仓库后执行：

```sh
python -m pip install Pillow
idf.py build
python scripts/release.py
python tools/verify_release.py releases/<生成的ZIP> --build-dir build
```

构建小程序版本时使用单独目录与配置，避免改写传统 USB 布局：

```sh
idf.py -B build-miniapp -DSDKCONFIG="$PWD/build-miniapp/sdkconfig" -DPASSPORT_MINIAPP=ON build
python tools/pack_miniapp.py --build-dir build-miniapp --output releases/AI-PASSPORT-Xiaozhi-2.1.0-xiaozhi.22-miniapp.bin
```

安装兼容测试使用上游协议 4 的真实分区与流式写入代码，见 `tests/miniapp_recovery/run.py --help`。测试替代的是无线、Flash 和硬件验镜像接口，不是微信客户端或卡上的实测。小程序版本使用的启动钩子来自 [FoloToy 安装器 127c56b](https://github.com/FoloToy/ai-passport-miniapp-installer/tree/127c56bc97b7ea85bf4bfd2b52ce4e2d80a30566/bootloader_components/recovery_boot_hook)，原 MIT 许可随源码保留。

依赖由 `dependencies.lock` 锁定，首次构建由 ESP-IDF 获取。源码已附带生成后的字库；只有重新生成字体时才需要 Node.js 和 `lv_font_conv@1.5.3`。字库来源、许可及生成步骤见 [字体说明](assets/fonts/README.md)。

完整测试命令和历次小智功能说明见 [构建与验证说明](XIAOZHI_BUILD.txt)。网页刷写器位于 [tools/web_flasher](tools/web_flasher)。

## 资源与许可

字体、音频来源及第三方库许可分别保存在 `assets/fonts`、`assets/licenses` 和相关 `vendor` 目录。其原始声明随源码与固件保留；字体许可不自动覆盖整个固件。项目未额外添加统一开源许可。

仓库不包含设备密钥、配网信息、产线身份台账、设备备份、运行日志、ESP-IDF SDK 或本机构建缓存。
